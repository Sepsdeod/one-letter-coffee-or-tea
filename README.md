One letter, and nothing else: **A** — coffee.

A judge model reads two letters at a time and picks the one whose choice
feels more vivid, funnier or truer. Coffee is the louder, more alive
answer: heat, bitterness, urgency, the ritual of mornings and deadlines.
Tea is gentle and quiet; coffee lands with a punch. And "A" is the first
letter — the primary answer, a confident, unhesitating stance rather than
a second choice.

## How to run it

`main.py` (Python 3.13, standard library only) writes the single letter to
the output directory:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py   # writes out/entry.txt
```

Running it twice produces byte-identical output: exactly one character,
`A`, valid UTF-8, no newline, no punctuation, no explanation.
